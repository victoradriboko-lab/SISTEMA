# Servitec 0.5.0

- Configurações → Sistema exibe versão instalada, consulta às Releases do GitHub e notas da versão disponível.
- Toda instalação exige senha de administrador e aprovação pelo botão Atualizar.
- Atualização manual por pacote JSON Servitec validado, com confirmação da versão de origem e SHA-256 dos arquivos.
- Backup consistente antes da troca, reinicialização supervisionada e recuperação dos arquivos anteriores se a nova versão não iniciar.
- Reversão do código preserva o banco, as credenciais e os dados atuais.

A ativação inicial deste recurso em uma instalação anterior exige atualizar pelo GitHub e reiniciar a tarefa Servitec-Sistema. As próximas versões podem ser aprovadas pela tela.
